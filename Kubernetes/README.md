# Architure of kubernetes

## K8s has 2 main type of components -
1. Control plane -
-  API Server
-  etcd
-  Scheduler
-  Control manager
-  Cloud control manager

2. Data plane - 
-  Kubelet
-  container runtime
-  Kube proxy
